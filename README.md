# Ask Joey

A little site to ask Joey out on a date.

- `index.html`: the question (good luck clicking "No")
- `Yes.html`: celebration
- `date.html`: the date (Monday, 12 October 2026) and where to go

Based on [Ask-for-a-Date-to-Crush-to-go-out](https://github.com/rising5-guru/Ask-for-a-Date-to-Crush-to-go-out) by Rising (MIT, see LICENSE).

To regenerate the backgrounds from a new wallpaper: `python tools/make_backgrounds.py path/to/wallpaper.jpg`
